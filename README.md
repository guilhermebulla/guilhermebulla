# Guilherme Bulla — BullaAcoustic
Voz & Violão · 28 anos de carreira · Shows e transmissões ao vivo

## Ecossistema

- **Site oficial** → https://guilhermebulla.github.io
  Portfolio público para contratantes. Documento técnico do repo: `SITE.md` na raiz.
- **AoVivokê** → github.com/guilhermebulla/karaoke
  Kit local de fila de karaokê offline (Node puro; telão + pedidos por celular).
- **Editor de repertório** → repo privado `editor-repertorio`
  Edita o `repertorio.json` (fonte única no site; espelho no karaoke).

## Funcionalidades do site

- **Conecte-se** (QR impresso nos shows) → guilhermebulla.github.io/conecte-se.html
- **Pedidos ao vivo** (fila em tempo real via Firestore) → guilhermebulla.github.io/pedidos.html
- **Repertório navegável** (1.200+ músicas, filtro e PDF) → guilhermebulla.github.io/repertorio.html
